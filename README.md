Banco INF101-Etapa 1

Trabalho da disciplina INF101 - Programação de Computadores I (UNIVIÇOSA).
sistema de cadastro e gestão de contas bancárias em C++, com menu(switch + do while).

Funcionalidades
Cadastrar conta(até 5 contas,usando vetores)
Consultar conta
Verificar saldo(somente conta ativa)
Alterar tipo da conta(somente conta ativa)
Ativar/Desativar conta

Como compilar e executar
```
g++ main.cpp -o banco
./banco
```
